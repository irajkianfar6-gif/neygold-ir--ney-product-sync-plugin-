=== NEY Product Sync - همگام‌ساز محصولات زرپلاس ===
Version: 2.2.0 | WordPress 6.0+ | PHP 7.4+ | WooCommerce 7+

استخراج محصولات فروشگاه زرپلاس (https://neygold.zar.plus) یکی‌یکی با همه تصاویر، توضیحات، مشخصات، وزن، قیمت و دسته‌بندی
و انتشار آن‌ها در فروشگاه ووکامرس پوسته NEY (neygold.ir).

== نصب ==
1. افزونه WooCommerce فعال باشد؛ واحد پول = تومان.
2. افزونه‌ها ← افزودن ← بارگذاری ← ney-product-sync.zip ← فعال‌سازی.
   (اگر نسخه قبلی ناقص NEY Product Sync نصب است، ابتدا آن را حذف کنید.)
3. منوی «همگام‌ساز زرپلاس» ← عیب‌یابی ← «آزمایش» تا استخراج یک محصول را ببینید، سپس «شناسایی خودکار API».
4. پیشخوان ← «استخراج و انتشار همه محصولات».
5. بعداً هر زمان: «بروزرسانی — افزودن جدیدترین محصولات» (همان دکمه بالای فهرست محصولات ووکامرس هم هست)
   یا در تنظیمات، بروزرسانی خودکار ساعتی/روزانه.

== منابع داده (به ترتیب) ==
JSON-LD، __NEXT_DATA__، داده‌های RSC نکست (با هدر RSC: 1)، API فهرست/جزئیات (خودکار یا دستی)،
سرویس رندر اختیاری و در نهایت DOM صفحه (عنوان، گالری، «مشخصات محصول»، قیمت، وزن).
فروشگاه زرپلاس فقط ۹ محصول اول را در HTML می‌فرستد و بقیه را با اسکرول و جاوااسکریپت بار می‌کند.
برای پوشش کامل یکی از این راه‌ها لازم است:
 - «شناسایی خودکار API» در عیب‌یابی (اگر موفق شود همه چیز خودکار است)؛
 - تب «جمع‌آوری از مرورگر» (بوکمارک، همه شناسه‌ها و آدرس API واقعی فروشگاه را می‌دهد)؛
 - سرویس رندر (مثل Browserless خودتان یا https://r.jina.ai/{raw}).
کشف از طریق «کالاهای مرتبط» هر محصول هم انجام می‌شود.

== آنچه منتشر می‌شود ==
محصول ساده ووکامرس: نام، توضیحات منبع، توضیح کوتاه (مشخصات)، قیمت نقدی، وزن، SKU = ZP-شناسه،
تصویر شاخص + گالری (بدون تکرار دانلود)، دسته‌بندی منبع (یا نوع جواهر از عنوان)، ویژگی‌ها (جنسیت، قطر، سایز...)
و فیلدهای پوسته NEY (_ney_type, _ney_img=photo, _ney_weight, _ney_material, _ney_gold, _ney_optn/_ney_options).
محصولاتی که حذف/زباله‌دان شوند دوباره اضافه نمی‌شوند.

== WP-CLI ==
wp neyps sync --mode=all
wp neyps sync            (فقط محصولات جدید)
wp neyps test 262368

== تغییرات 2.2.0 ==
- اتصال مستقیم به API واقعی زرپلاس (api.admin.zar.plus/api/mini-app/products) برای فهرست و جزئیات کامل.
- بوکمارک نسخه ۲: جزئیات کامل همه محصولات را در مرورگر می‌گیرد و فایل نتیجه را دانلود می‌کند؛ انتخاب فایل در افزونه.
- اگر سرور به زرپلاس دسترسی نداشته باشد، انتشار فقط از داده‌های مرورگر انجام می‌شود و دیگر معطل نمی‌شود.
- دسته = نوع جواهر بدون جنسیت («دستبند» نه «دستبند زنانه»)؛ جنسیت از نام محصول.
